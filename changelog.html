Cube Pattern — changelog

Release notes for the 3D cube memory game · Last updated 6 November 2026

Current version: 1.0.0 (November 2026). Cube Pattern is a free 3D cube memory game for iPhone, iPad and Android with 100 levels, a daily challenge, four game modes and offline play.

1.0.0 — first public release (6 November 2026)

  • 100 story levels across 10 chapters and the three-round Master Cube finale.
  • Daily Challenge with a streak that survives one missed day.
  • Four modes: Memory Climb, 60s Blitz, Zen and Daily Challenge.
  • Memory profile with eight skill dimensions, achievements and weekly leaderboard.
  • Shop with coin cosmetics, collections, starter pack and premium (monthly, yearly, lifetime).
  • Optional rewarded ads for extra coins — never required.
  • Account support: guest play, optional Google sign-in, cloud sync and in-app account deletion.
  • Localized in English, Turkish, German, Spanish, French and Portuguese.
  • Privacy: analytics and crash reporting are opt-in; no feed, no chat.
