Games like Simon: sequence and memory games (2026)

Editorial guide by Baripas Studio · Last updated 6 November 2026

Quick answer. Simon is the classic sequence-memory game: watch a growing sequence of lights and sounds, then repeat it. If you want that loop with a 3D twist, try Cube Pattern — you memorize tile positions on a rotating cube and rebuild the pattern in order. For pure Simon clones, search your app store for “Simon memory”; for logic instead of memory, try Mastermind.

Other memory loops to try

  • Simon-style apps — the closest to the original; look for no-ads versions.
  • Memory match — pair recognition instead of sequence.
  • Mastermind — deduction, not memory, but same “brain game” mood.
  • Cube Pattern — spatial sequence memory on a 3D cube, free and offline.

Which should you pick?

Choose Simon-style if you want fast, endless reflex memory. Choose Cube Pattern if you want a slower, spatial challenge with levels and a daily goal. Choose Mastermind if you prefer logic to memory.

Frequently asked questions

What is the best game like Simon?

For a 3D twist, Cube Pattern; for a direct clone, a Simon-style app from your store. Cube Pattern is free, offline and adds levels, stars and a daily challenge.

Is Cube Pattern like Simon?

Both are sequence-memory games; Cube Pattern adds a rotating 3D cube, spatial layout and progression.

Are there free Simon games?

Yes, many free Simon clones exist on iOS and Android; ad policies vary, so check the listing.
