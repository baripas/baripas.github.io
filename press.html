About the game

Cube Pattern turns the classic memory-test loop into a 3D spatial challenge. A pattern of tiles lights up across the faces of a cube; when it disappears, the player rotates the cube and taps the tiles in the correct order. Later levels add extra faces, decoy tiles, hidden faces, reverse order, single-look memory and mirrored patterns, ending with a three-round Master Cube exam. A daily challenge and weekly leaderboard give players a reason to return, while Zen mode offers low-pressure practice.

About Baripas Studio

Baripas Studio is an independent single-player mobile game studio based in Türkiye. It builds calm, focused games with no feed, no chat and no pay-to-win: Cube Pattern, Swipe Clone and Angle Dare. The studio's principles include offline-first play, optional accounts, opt-in analytics and in-app account deletion. More: about Baripas Studio.
